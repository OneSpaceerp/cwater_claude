# C-Water Complete Website Blueprint

## Premium Futuristic B2B Water-Treatment Experience

### Strategic Position

**Master brand:** C-Water
**Markets:** Egypt first, regional-ready for GCC/Africa
**Languages:** English + Arabic
**Primary commercial goal:** Qualified lead generation
**Primary brand goal:** Establish C-Water as a premium integrated water-treatment engineering partner
**Commercial model:** Technical catalog + Request Quote / Request Solution
**Brand system:** Existing C-Water logo and color palette retained; surrounding visual language redesigned

The current C-Water website is centered on broad water-treatment solutions, equipment and chemicals. The new experience should move the business toward a much stronger proposition: **one integrated partner across treatment chemistry, filtration, dosing, sensing, control, engineering and service**.

The combined technology proposition is credible because Walchem currently integrates sensors, electronic metering pumps, controllers and remote water-management capabilities; TIMEX provides broad filtration technologies; and Kurita positions its solutions around customized treatment programs, system optimization, reliability, water/energy efficiency and lifecycle performance.

## 4.2 Visual Character

Use the existing C-Water colors, but introduce a more sophisticated design language around them:

* deep technical backgrounds;
* high-contrast typography;
* large editorial headlines;
* precise grid layouts;
* layered transparency;
* technical line graphics;
* controlled gradients derived from the C-Water palette;
* fluid visual movement;
* photographic industrial detail;
* engineering diagrams;
* data visualization.

The exact existing brand colors should be retained as source-of-truth values rather than recreated approximately.
